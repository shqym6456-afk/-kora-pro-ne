# كورة برو — تجهيز الهاتف فقط

هذه النسخة تعرض المباريات والأحداث المباشرة وتفاصيل المباراة والتشكيلات والإحصائيات والترتيب. أزيلت منها مسابقات توقع النتائج والجوائز.

## 1) نشر خادم البيانات
1. ارفع هذا المجلد إلى مستودع GitHub خاص.
2. أنشئ خدمة Node.js على مزود استضافة يدعم Node 22، واربطها بالمستودع.
3. أمر التشغيل: `npm start`.
4. أضف متغير البيئة `API_FOOTBALL_KEY` في لوحة الاستضافة، والصق المفتاح هناك فقط. لا تضعه في `public/config.js` أو في GitHub أو داخل APK.
5. بعد النشر افتح `https://رابط-الخادم/healthz` وتأكد أن `provider` هو `api-football` وأن `mock` تساوي `false`.

## 2) ربط التطبيق بالخادم
افتح `public/config.js` وعدّل السطر الأخير ليصبح:
`window.KORA_API_BASE = "https://رابط-الخادم";`
استخدم رابط HTTPS الحقيقي من مزود الاستضافة، دون شرطة مائلة في النهاية. احفظ التغيير وارفعه إلى GitHub.

## 3) بناء APK من الهاتف
1. افتح المستودع في GitHub من المتصفح.
2. افتح تبويب Actions وفعّل Actions إذا طُلب منك ذلك.
3. اختر `Build Kora Pro APK` ثم `Run workflow`.
4. انتظر حتى تنتهي العملية بنجاح.
5. افتح تشغيل البناء الناجح، وانزل إلى Artifacts، ثم نزّل `kora-pro-debug-apk`.
6. فك ضغط الملف على الهاتف، ثم ثبّت `app-debug.apk`. قد يطلب Android السماح بالتثبيت من المتصفح أو مدير الملفات.

## ملاحظات
- هذا ملف APK تجريبي (debug) للتجربة الشخصية، وليس إصدار متجر موقّعاً.
- يجب نشر الخادم أولاً وتعديل `config.js` قبل بناء APK؛ وإلا ستفتح الواجهة لكن لن تصل إلى بيانات المباريات.
- المفتاح يبقى سرياً في إعدادات الخادم. إذا ظهر في مستودع عام، ألغِه وأنشئ مفتاحاً جديداً.
- حدود API-Football تختلف حسب الخطة. لا تضمن الخطة المجانية تحديثاً حياً كل 15 ثانية؛ راقب الحصة من `/healthz`.
- قد تحتاج حسابات الاستضافة أو ضبط إعداداتها إلى مساعدة ولي أمر.
